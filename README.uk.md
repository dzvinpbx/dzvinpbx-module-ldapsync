# Модуль синхронізації користувачів LDAP/AD для Dzvin PBX

[![GitHub release](https://img.shields.io/github/v/release/dzvinpbx/dzvinpbx-module-ldapsync)](https://github.com/dzvinpbx/dzvinpbx-module-ldapsync/releases)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**Українською** | **[English](README.md)**

Синхронізує співробітників з Active Directory та інших LDAP-серверів у Dzvin PBX і автоматично
створює облікові записи користувачів. Після призначення внутрішнього номера дані про нього можна
записати назад у каталог.

> Це форк модуля MikoPBX **ModuleLdapSync** для Dzvin PBX — див. розділ [Походження](#походження).

## Можливості

- Імпорт користувачів з Active Directory, OpenLDAP, 389 Directory Server і FreeIPA
- LDAP, LDAP + STARTTLS і LDAPS з необов’язковою перевіркою сертифіката сервера та власним пакетом ЦС
- Зіставлення атрибутів: ім’я, мобільний номер, внутрішній номер, e-mail, фото, стан облікового запису
- Необов’язкова двостороння синхронізація: внутрішній номер, мобільний номер, e-mail, аватар і пароль SIP записуються назад у каталог
- Фільтри за підрозділом і додатковий фільтр користувачів
- Періодична фонова синхронізація (щогодини, кожні 5 хвилин, поки виявляються зміни) і ручний запуск
- Журнал конфліктів для записів, які не вдалося синхронізувати
- Перевірка підключення до LDAP і отримання списку користувачів до ввімкнення синхронізації

## Вимоги

- Dzvin PBX 2025.1.1 або новіша (PHP 8.4)

## Встановлення

1. Відкрийте **Модулі** → **Маркетплейс** в адмінпанелі Dzvin PBX
2. Знайдіть **Синхронізація LDAP/AD**
3. Натисніть **Встановити**

Або з релізу GitHub: завантажте `.zip`, потім **Модулі** → **Встановлення модуля**.

## Використання

1. Додайте сервер: адреса, порт, режим передавання, обліковий запис для підключення і корінь домену (Base DN).
2. На вкладці **Поля синхронізації** вкажіть назви атрибутів, які використовуються у вашому каталозі.
3. Виконайте **Перевірку підключення** і тест списку користувачів, потім увімкніть сервер.
